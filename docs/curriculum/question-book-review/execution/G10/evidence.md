## Kontrollera kylarvätskenivån

Kia, manufacturer owner handbook. MQ4 / 2022 / Swedish manual; live manufacturer edition, no revision date shown. [Source](https://ownersmanual.kia.com/full_webhelp/MQ4/2022/sv_SE/topics/chapter7_8_1.html).

Scope: Manufacturer technical warning for a conventional pressurised cooling system. Actual radiator/expansion-tank layout and stopping instructions vary: use own handbook/recovery advice.
